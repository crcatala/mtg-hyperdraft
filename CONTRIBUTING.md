# Contributing

Thanks for your interest in HyperDraft.

This is a personally maintained hobby project. I'm happy to hear about bugs and ideas, but I'm generally
not accepting code contributions.

## Issues

Bug reports and feature ideas are welcome as [GitHub issues](https://github.com/crcatala/mtg-hyperdraft/issues).
Please search existing issues first. A good bug report includes:

- what you did and what you expected, with steps to reproduce;
- whether it happened in solo mode, a local `npm run dev` room or a deployed site;
- your browser and operating system, and any console errors.

Ideas are considered, but there's no promise they'll be built, and issues may be closed without a fix.

## Pull requests

Pull requests generally aren't accepted, and unsolicited ones may be closed without review. If you have a
fix you'd like to share, open an issue describing it first.

## Security issues

Please don't report security vulnerabilities in a public issue. See [SECURITY.md](SECURITY.md).

## Forks

You're welcome to fork HyperDraft, adapt it and host your own copy under the terms of the
[MIT License](LICENSE). Please keep it free, and keep the
[Fan Content Policy](https://company.wizards.com/en/legal/fancontentpolicy) notice and the credits in
the [README](README.md#credits).
